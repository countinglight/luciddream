# Developer script reference

Run commands from the repository root after `npm ci`. The developer workflow and prerequisites are
in [BUILD.md](../BUILD.md). Add an entry here whenever a utility is added to this directory.

| Script                                                 | Command / caller                                                                              | Purpose and effects                                                                                                                                                                                                                                                                                               |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [android-emulator.js](android-emulator.js)             | `npm run emulator:plan`, `emulator:start`, `emulator:check`, `emulator:doze`, `emulator:wake` | Finds Android SDK tools; plans, creates, boots, inspects, or controls the emulator. `plan` is read-only; `doze` and `wake` change device power state. See [Emulator](../BUILD.md#emulator).                                                                                                                       |
| [build-number.js](build-number.js)                     | Imported by `app.config.js`, release and version helpers                                      | Computes platform build numbers from the package version and `LUCIDDREAM_BUILD`. Library module, not a standalone command. See [Versioning](../BUILD.md#versioning).                                                                                                                                              |
| [check-line-endings.js](check-line-endings.js)         | `npm run line-endings:check`                                                                  | Checks present tracked text files for CRLF, ignoring tracked files pending deletion; exits nonzero on violations without changing files.                                                                                                                                                                          |
| [check-telemetry-config.js](check-telemetry-config.js) | `node scripts/check-telemetry-config.js`; part of `npm run deploy:telemetry`                  | Checks that the D1 database ID is configured before deployment; no writes. See [Diagnostics service](../BUILD.md#9-diagnostics-service).                                                                                                                                                                          |
| [clean-build.js](clean-build.js)                       | `npm run clean:build`                                                                         | Deletes generated build/cache directories under the current working directory. Run only from the repository root.                                                                                                                                                                                                 |
| [generate-tones.js](generate-tones.js)                 | `node scripts/generate-tones.js`                                                              | Synthesizes and overwrites bundled WAV tones under `assets/sounds/`. Requires Node only.                                                                                                                                                                                                                          |
| [mark-prototype-headers.js](mark-prototype-headers.js) | `node scripts/mark-prototype-headers.js`; part of `npm run deploy:prototype`                  | Adds the prototype noindex header to `dist/_headers`; requires an existing web export. Does not deploy by itself.                                                                                                                                                                                                 |
| [release.js](release.js)                               | `npm run release -- <major\|minor\|patch\|x.y.z> [--dry-run]`                                 | Checks the working tree, updates version files, commits, and tags; never pushes. See [Release to testers](../BUILD.md#release-to-testers).                                                                                                                                                                        |
| [sync-bundled-scripts.js](sync-bundled-scripts.js)     | `npm run generate:bundled-scripts`; automatic pre-start/build/test hooks                      | Regenerates `src/storage/bundled-scripts.ts` from `assets/scripts/*.yaml`.                                                                                                                                                                                                                                        |
| [sync-signals.js](sync-signals.js)                     | `npm run sync:signals -- [options]`; `npm run check:content`; `npm run check:audio`           | Repairs signal manifest entries and reports broken script references. The mandatory content check needs Node only. Optional encoding inspection requires FFprobe; conversion also requires FFmpeg. See [Maintaining the signal catalog](../BUILD.md#maintaining-the-signal-catalog) for all options and examples. |
| [version-info.js](version-info.js)                     | `npm run version:info [-- --json]`                                                            | Prints version and platform build numbers; reads local files and `LUCIDDREAM_BUILD`, with no writes or network access.                                                                                                                                                                                            |
| [tests/sync-signals.cjs](tests/sync-signals.cjs)       | `npm run test:signals`                                                                        | Runs catalog/reference tests. Set both `FFMPEG_PATH` and `FFPROBE_PATH` to enable real audio conversion and CLI integration tests using temporary fixtures.                                                                                                                                                       |

`npm run sync:signals -- --help` lists the catalog options, including `--check` (read-only),
`--skip-audio`, `--no-transcode`, `--mono`, `--ffmpeg`, `--ffprobe`, and `--content-dir`. Other package commands
(builds, validation, deployment, updates, and device tests) are documented in [BUILD.md](../BUILD.md).
