The script format

A script is a YAML document describing what to play through the night. There is no separate language to learn beyond the handful of statements below, and no editor to fight: write one in any text editor, keep it in a file, and add it to the app.

Shape

A script has a name, a version, an optional master volume, and a body — a list of statements executed in order. Each statement is a single-key mapping whose key names what it does. 

name: MILD with REM targeting
version: 1
volume: 0.4                        # master gain for this script, 0..1

body:
  - log: "run started"
  - wait: 90m                      # let the first sleep cycle pass

  - repeat: 6                      # finite loop
    body:
      - play: chime
      - wait: 10s
      - play: bell
      - wait: 20m

  - with: { gain: 0.6 }            # scoped: applies to everything inside
    body:
      - repeat: infinite
        until: { elapsed: { gte: 8h } }
        body:
          - if: { all: [{ rem: true }, { hr: { lt: 60 } }] }
            then:
              - play: { signal: chime, gain: 0.8, wait: true }
              - wait: 3s
              - play: chime
            else:
              - wait: 5m

Statements

Statement Form What it does
play play: <name> or play: { signal, gain?, rate?, wait? } Plays a signal. gain multiplies the gain of the enclosing scope. wait: true blocks until playback finishes; by default the script carries on immediately.
wait wait: 10s · 2m · 1h30m Pauses for a duration.
repeat repeat: <n> or infinite, with body: and optional until: A loop. until is checked before each pass. An infinite loop with no until runs until you stop the run.
if if: <condition>, then:, optional else: A branch.
with with: { gain?, rate? }, body: Applies an effect to everything inside it. Nested scopes multiply. gain and rate are the only effects available.
set set: { volume: 0.3 } Changes the master volume for the rest of the run.
log log: "text" Writes your own marker into the run log.
stop stop: Ends the run cleanly.

Durations

Durations are a number followed by a unit — ms, s, m, h — and can be joined, as in 1h30m. Anywhere a duration is accepted you may instead write $short, $medium or $long, which expand to the period presets configured in the app's Settings. Referring to a preset that has no value configured is an error the app reports by name before the run starts.

Conditions

Conditions compare a context field using eq, ne, lt, lte, gt or gte, and combine with all, any and not.

Field Type Where the value comes from
elapsed duration Time since the run started
clock "HH:MM" The device clock
iteration number Index of the enclosing repeat, counting from zero
hr, hrv number A context provider
rem true / false A context provider
sleepStage awake · light · deep · rem A context provider
  • A field with no reading is false. If nothing is providing a value, the condition simply does not hold, the app notes it in the log, and the script carries on rather than stalling.
