Install

Getting LucidDream onto your phone

The Android build is the one to use for a real night. It is handed out directly as an APK file rather than through the Play Store, so the installation takes two more taps than usual and your phone will say so.

Android, step by step

  1. Download the file

    Tap the button above on the phone itself. The file lands in your Downloads.

  2. Open it, and allow the install

    Android will ask whether this app — your browser or file manager — may install unknown apps. Allow it, then come back and open the file again.

  3. Expect a Play Protect warning

    Google has not scanned this build, because it did not come through the Play Store. The warning is about the delivery route, not about anything found in the app. Choose the option to install anyway.

  4. Open it and grant notifications

    The notification is how a run shows its progress and its Stop button while the screen is off, so the app needs it to work properly.

  • The microphone is optional. It is requested only if you turn on the gentle voice interrupt in Settings, and only to measure how loud the room is. Leave that setting off and the app never asks.
  • Updating. Download a newer APK and install it over the top; your library, settings and logs stay where they are. If the signing key ever changes you would have to uninstall first, which deletes them — so export anything you want to keep before a reinstall.
  • Over a cable, if you prefer. With USB debugging on, the equivalent is adb install luciddream-v0.5.0-release.apk.

In a browser

Open the web app — there is nothing to install. It is the same application, and it is the quickest way to write scripts, build a library, and see how the interface works. Your browser can add it to the home screen if you want it to open like an app.

  • Do not rely on it overnight. Browsers throttle tabs that are not in front, and a sleeping laptop or a locked phone will not keep a tab running the way the Android build keeps a foreground service running. Use the browser to explore and the Android build to sleep.
